# 支付自己（Pay Yourself First）

## 这个 Skill 做什么

把“有剩余再存钱”改成“收入到账先给未来的自己留钱”。根据现金流选择一个能长期坚持的起步比例，分离消费与储蓄账户，并把转账安排在发薪日自动执行，逐步建立应急金和长期投资本金。

## 核心原则
先把自己当作最重要的债权人。收入一到手，立刻按固定比例存入独立账户，剩下的才用于生活。这是财富积累的第一引擎。

## 执行步骤
1. **确定比例**：起步至少 10%，理想 20% 或更高。如果当前债务重，可从 5% 开始，但必须启动。
2. **开立专用账户**：独立储蓄/投资账户，与日常消费账户完全分离。不要用“剩余再存”的方式。
3. **自动化**：设置发薪日自动转账。当天或次日执行，绝不依赖意志力。
4. **加薪规则**：每次加薪或额外收入，至少把 50% 以上新增部分直接转入“支付自己”账户。
5. **破除借口清单**（常见4个）：
   - “收入太低” → 先从最小金额开始，建立身份认同
   - “这个月特殊” → 特殊月份也转，保持连续性
   - “先还债再存” → 并行：最低还款 + 强制储蓄
   - “等有闲钱再存” → 永远不会有“闲钱”

## 判停标准
- 连续 3 个月自动完成转账
- 能说出自己的储蓄比例和账户结构
- 对“存不下”的借口有自动反驳
