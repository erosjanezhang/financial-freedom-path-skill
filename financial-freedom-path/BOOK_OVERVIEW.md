# BOOK_OVERVIEW — 《财务自由之路》系列（博多·舍费尔）

## 元信息
- 主书：财务自由之路：7年内赚到你的第一个1000万（Der Weg zur finanziellen Freiheit）
- 作者：博多·舍费尔（Bodo Schäfer）
- 系列其他：Ⅱ（3年内资产翻一番）、Ⅲ（投资组合体系）、以及系列合集
- 核心定位：欧洲金钱教练的系统化财务自由方法论，强调“先配得上财富，再拥有财富”

## 主旨（Adler 结构分析）
作者认为财富是人与生俱来的权利，但大多数人因为价值观冲突、责任逃避、债务、不储蓄、不会“饲养”金钱而无法实现。全书提供一套可执行的路径：改变金钱观 → 清理债务 → 提高收入 → 强制储蓄 → 复利投资 → 三阶段目标（保障→安全→自由）→ 教练与环境 → 播种（捐赠）。

## 四大致富支柱
1. 梦想（Dream Book）
2. 目标（清晰、可衡量、与价值观一致）
3. 价值观（必须与目标对齐，否则内耗）
4. 策略（储蓄、投资、增收、从加薪中再储蓄）

## 批判与边界
- 优势：步骤清晰、强调心理与行为、可立即行动
- 局限：部分数字（7年、收益率）依赖个人执行力与市场环境；投资建议需结合当地法规与风险承受能力
- 适用：工薪族、创业者、想系统性改变金钱关系的人
- 不适用：纯粹投机、短期暴富幻想

- 饲养金钱
