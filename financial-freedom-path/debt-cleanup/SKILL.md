# 债务清理

## 这个 Skill 做什么

先把“我欠了很多钱”的压力变成一张包含余额、利率、最低还款和期限的清单，再选择最高利率优先或最小余额优先的策略。给出停止新增债务、与债权人沟通、保留最低应急能力及逐月检查进度的具体方案。

## 核心原则
债务是财富的反向复利。先停止新增高息债务，再按优先级攻击，同时保留最低限度的“支付自己”储蓄，避免心理崩溃。

## 执行步骤
1. **全面盘点**：列出所有债务（本金、利率、最低还款、到期日）。
2. **分类**：高息消费债 vs 低息生产性债（房贷等可后置）。
3. **停止出血**：砍掉不必要消费，取消可导致新债的额度冲动使用。
4. **攻击顺序建议**：
   - 优先最高利率的债务（数学最优）
   - 或最小余额的债务（雪球法，快速获得心理胜利）
5. **并行原则**：即使在还债，也保持小额强制储蓄（建立新身份）。
6. **谈判与重组**：联系债权人，询问是否可降息、延期或合并。
7. **预防**：建立应急金后，再考虑大额消费；用现金或全款思维替代分期诱惑。

## 判停
- 所有高息债务清零
- 有明确的“不再新增消费债”规则
- 能在没有债务压力的情况下继续储蓄
