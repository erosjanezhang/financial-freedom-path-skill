# INDEX — 财务自由之路 Skill Pack

基于博多·舍费尔《财务自由之路》系列蒸馏的可执行 skills。

## 技能列表

| Skill | 触发场景 | 核心产出 |
|-------|----------|----------|
| pay-yourself-first | 想开始储蓄、总是存不住钱、每月花光 | 强制储蓄系统 + 自动化方案 |
| three-stages-financial-freedom | 不知道财务自由目标怎么定、感觉目标太大 | 三阶段目标计算 + 行动计划 |
| increase-income | 收入停滞、想快速提高收入 | 12条增收法则落地清单 |
| debt-cleanup | 有债务压力、不知道先还哪个 | 债务清理优先级 + 13建议 |
| compound-feeding-money | 有了积蓄不知如何投资、怕风险 | 饲养金钱原则 + 基础配置思路 |
| values-goals-alignment | 目标和行动总对不上、内心冲突 | 价值观-目标对齐工作表 |
| coach-network | 想找导师/教练、环境拖后腿 | 教练选择与专家网络构建 |

## 推荐调用顺序（新手路径）
1. values-goals-alignment（先对齐内在）
2. debt-cleanup（清理拖累）
3. pay-yourself-first（建立系统）
4. increase-income（加速）
5. three-stages-financial-freedom（设定里程碑）
6. compound-feeding-money（让钱工作）
7. coach-network（确保执行）

## 来源
- 主书：财务自由之路：7年内赚到你的第一个1000万
- Ⅱ：3年内让你的个人资产翻一番
- Ⅲ：投资组合体系（Wohlstand ohne Stress）
