# INDEX — 财务自由之路 Skill Pack

基于博多·舍费尔《财务自由之路》系列蒸馏的可执行 skills。

## 技能列表

| Skill | 解决的问题 | 核心产出 |
|-------|----------|----------|
| `values-goals-alignment` | 金钱信念与目标冲突，行动容易中断 | 信念诊断、价值观排序、目标重写与梦想手册 |
| `debt-cleanup` | 多笔债务压身，不知道还款顺序或如何停止以债养债 | 债务盘点、偿还优先级、止血规则与阶段计划 |
| `pay-yourself-first` | 每月花光，无法稳定储蓄 | 储蓄比例、账户结构、自动转账与加薪规则 |
| `increase-income` | 收入或报价停滞，不清楚突破口 | 瓶颈诊断、价值证明与短期增收动作 |
| `three-stages-financial-freedom` | 财务自由目标抽象，不知道需要多少钱 | 三阶段目标数字、差距分析与倒推计划 |
| `compound-feeding-money` | 已有结余但不会开始长期投资，或容易追涨杀跌 | 资金分层、持续投入、分散和再平衡原则 |
| `coach-network` | 知道方法却执行困难，缺少问责或专业支持 | 教练筛选、合作规则与专家网络计划 |

## 推荐调用顺序（新手路径）
1. values-goals-alignment（先对齐内在）
2. debt-cleanup（清理拖累）
3. pay-yourself-first（建立系统）
4. increase-income（加速）
5. three-stages-financial-freedom（设定里程碑）
6. compound-feeding-money（让钱工作）
7. coach-network（确保执行）

- 主书：财务自由之路：7年内赚到你的第一个1000万
- Ⅱ：3年内让你的个人资产翻一番
- Ⅲ：投资组合体系（Wohlstand ohne Stress）
