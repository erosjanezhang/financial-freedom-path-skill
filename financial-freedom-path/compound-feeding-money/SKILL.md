# 饲养金钱与复利

## 这个 Skill 做什么

帮助用户先区分哪些钱必须保持安全、哪些钱可以长期承受波动，再建立简单、低成本、分散且可持续投入的投资框架。重点是时间、纪律和风险承受能力，不是寻找下一只热门资产或短期择时机会。

## 核心隐喻
金钱像动物：你要定期喂养（投入）、给它成长空间（时间）、选择合适的环境（资产类别），它才会繁殖。

## 关键原则
1. **时间是最大杠杆**：越早开始，复利越惊人。
2. **持续投入**：定额定期（DCA）比择时更可靠。
3. **风险匹配**：保障阶段的钱只放极低风险；安全与自由阶段可逐步提高权益类比例。
4. **分散与简单**：优先低成本、透明、长期可持有的工具（指数基金等），避免复杂产品。
5. **费用是隐形杀手**：关注管理费、交易费。
6. **情绪管理**：市场波动时坚持既定计划，不因恐惧或贪婪偏离。

## 与三阶段的对应
- 保障：现金/货币基金/短债
- 安全：股债平衡、全球分散
- 自由：可提高权益，但仍需再平衡与风险控制
