# 财务自由之路 Skill Pack

本包将《财务自由之路》系列的核心方法论拆成可独立调用的原子 skills。

## 路由规则

根据用户当前最主要的问题，只读取对应的子技能文件；问题横跨多个阶段时，按需读取多个文件，并整合成一个计划：

- 存不住钱 → 读取 [`pay-yourself-first/SKILL.md`](pay-yourself-first/SKILL.md)
- 目标太大不知从何开始 → 读取 [`three-stages-financial-freedom/SKILL.md`](three-stages-financial-freedom/SKILL.md)
- 收入上不去 → 读取 [`increase-income/SKILL.md`](increase-income/SKILL.md)
- 有债务压力 → 读取 [`debt-cleanup/SKILL.md`](debt-cleanup/SKILL.md)
- 有钱不知怎么投 → 读取 [`compound-feeding-money/SKILL.md`](compound-feeding-money/SKILL.md)
- 内心对钱有冲突 → 读取 [`values-goals-alignment/SKILL.md`](values-goals-alignment/SKILL.md)
- 执行不下去 → 读取 [`coach-network/SKILL.md`](coach-network/SKILL.md)

需要总览、推荐调用顺序或核心术语时，读取 [`INDEX.md`](INDEX.md)、[`DIGEST.md`](DIGEST.md) 或 [`BOOK_OVERVIEW.md`](BOOK_OVERVIEW.md)。

## 使用方式
直接对 agent 说具体问题，例如：
- “帮我用支付自己的方法设计储蓄计划”
- “按三阶段帮我算财务保障和财务安全目标”
- “我有信用卡债，怎么按书中方法清理”

读取对应子 skill 后给出可执行步骤。先询问完成计算或排序所必需的信息；信息不足时明确列出假设，不编造用户的收入、支出、债务、收益率或风险承受能力。

## 注意
本 skill 提供教育性框架与一般决策支持，不构成个性化投资、税务或法律建议。不要承诺收益或保证实现财务自由；涉及具体金融产品、税务、法律或高风险决策时，建议用户结合当地法规并咨询持证专业人士。
