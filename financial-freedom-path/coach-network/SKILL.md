# 教练与专家网络

## 核心洞察
大多数人失败不是因为方法错，而是缺少外部问责与更高标准的环境。“教练法则”是加速器。

## 执行步骤
1. **定义需求**：你现在最需要的是知识、问责、人脉还是情绪支持？
2. **寻找教练/导师**：
   - 已经走在你想走的路上的人
   - 愿意直言、有结果的人
   - 可付费或通过价值交换获得时间
3. **规则**：约定频率、形式、你必须完成的作业、如何衡量进展。
4. **专家网络**：在投资、税务、法律、健康等领域各有至少 1 个可咨询的人。
5. **环境升级**：减少长期待在“金钱负面”或“受害者心态”的圈子；主动加入更高标准的社群。
6. **成为别人的教练**：教是最好的学，也能强化自己的身份。

## 判停
- 有明确的教练或问责伙伴
- 每季度至少与 1–2 位相关领域专家交流
- 日常环境中正面金钱对话占比提升
