# 价值观与目标对齐 + 梦想手册

## 为什么重要
如果潜意识认为“金钱不好”或“富有的人自私”，任何储蓄和投资计划都会被自我破坏。价值观必须与目标同向。

## 执行步骤
1. **金钱观诊断**：写下你从小听到的关于钱的句子，以及你现在真实的感受（好/坏/危险/自由等）。
2. **ABC 法**（示例）：
   - A（激活事件）：看到有钱人炫耀
   - B（信念）：有钱人都很虚伪
   - C（结果）：自己也不敢追求更多钱
   - 挑战 B，换成更有用的信念。
3. **价值观排序**：列出对你真正重要的 5–8 个价值观，检查是否与“财务自由”目标冲突。
4. **梦想手册**：用文字+图片收集你真正想要的生活画面（不是别人期望的）。每周翻看。
5. **目标重写**：把财务目标改写成与核心价值观一致的语言（例如“为了有时间陪伴家人并保持健康”）。

## 判停
- 能清晰说出自己对金钱的真实信念
- 财务目标与至少 3 个核心价值观直接相连
- 有正在使用的梦想手册
