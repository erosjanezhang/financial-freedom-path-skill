# 如何增加自己的收入

## 核心洞察
收入很大程度上由你的自我价值、专业可见度和解决问题的能力决定。单纯“更努力”不够，必须系统提升可被市场定价的价值。

## 实用法则（落地版）
1. **展示强项**：把你做得最好的事变成可被看见的成果（作品集、案例、数据）。
2. **成为专家**：在一个细分领域持续输出，建立“找他就对了”的认知。
3. **解决高价值问题**：优先做能直接帮客户/老板省钱或赚钱的事。
4. **提高要价勇气**：定期审视自己的时薪/项目价，主动提出上调（用成果说话）。
5. **创造被动或半被动收入流**：产品化知识、授权、投资、数字产品等。
6. **环境与圈子**：主动接近比你收入高、思维更开阔的人。
7. **持续学习高杠杆技能**：销售、沟通、财务、某个技术深度。
8. **记录与复盘**：每周记录“我创造了什么可量化价值”。

## 立即行动检查
- [ ] 我当前收入的主要瓶颈是能力、可见度还是要价？
- [ ] 本周能完成的一个“展示强项”动作是什么？
- [ ] 下一次谈薪/报价时，我准备用哪些成果支撑？
